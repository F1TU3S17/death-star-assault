# Атака на Звезду Смерти

Браузерная 3D-игра по **«Звёздным войнам: Эпизод IV — Новая надежда»**. Выберите X-wing Красной эскадрильи или Y-wing Золотой эскадрильи, пробейте коридор к станции и завершите битву при Явине. Это самостоятельная некоммерческая фанатская игра, не официальный продукт Lucasfilm.

## Быстрый запуск

На Windows дважды щёлкните **`START.bat`**. Скрипт запустит локальный сервер и откроет браузер на **http://127.0.0.1:4173**. Окно сервера оставьте открытым; для остановки нажмите `Ctrl+C`.

Нужен **Node.js 22.7+** и современный браузер с WebGL2. Готовая папка `dist/` входит в рабочую поставку: для её запуска достаточно Node.js, без установки npm-пакетов и без интернета. Открывать `index.html` через `file://` не следует.

Из терминала:

```powershell
cd D:\vibe\death-star-assault
npm start
```

Если сборка отсутствует, `START.bat` установит зависимости и соберёт игру. Для разработки:

```powershell
npm ci
npm run dev
npm test
npm run build
```

После изменения исходников выполните `npm run build`, чтобы обновить игру, запускаемую через `START.bat`. `npm run dev` использует исходники сразу.

`npm test` проверяет миссии, симуляцию и файлы моделей. При наличии готовой сборки и установленного Chromium также запускается браузерный тест. Если он пропущен из-за отсутствия браузера, установите тестовый Chromium командой `npx playwright install chromium`. PNG-снимки проверки сохраняются во временную папку системы `death-star-assault-qa`, отдельно от игры.

## Управление

| Действие | Клавиши |
|---|---|
| Изменить направление | `W A S D` |
| Предыдущее / следующее оружие | `←` / `→` (также `↓` / `↑`) |
| Перезарядить торпедные пусковые | `R` |
| Крен | `Q` / `E` |
| Ускорение | Удерживать `Shift` |
| Снизить тягу для точного захода | Удерживать `Ctrl` |
| Огонь выбранным оружием | Удерживать `Пробел` / левую кнопку мыши |
| Вид из кабины / от третьего лица | `C` |
| Оборудование корабля | `F` |
| Энергия: двигатели / оружие / щиты / баланс | `1` / `2` / `3` / `4` |
| Ремонт астродроидом | `V` |
| Вызов пары ведомых | `T` |
| Сложить / раскрыть S-foils X-wing | `X` |
| Пауза / продолжение | `Esc` |

Щелчок по игровому полю включает управление мышью, если браузер поддерживает захват указателя. Клавиатура работает независимо. При уходе с вкладки игра ставится на паузу. Подсказки финального QTE используют физические клавиши `A`, `D`, `W`, затем `Пробел` и работают при русской раскладке.

## Кампания

1. **Красная эскадрилья.** Уничтожьте пять TIE, прикрывая ударную группу.
2. **Открыть коридор.** Подавите четыре батареи на поверхности.
3. **Золотая группа.** Сопроводите три Y-wing через три точки маршрута. Держитесь в пределах 700 м и перехватывайте атакующие TIE. Потеря всей группы завершает вылет поражением.
4. **Прикрыть Красного Два.** Защитите повреждённый X-wing Клина и уничтожьте четырёх преследователей.
5. **Траншейный заход.** Пройдите шесть створов, избегая стен, огня ведомых и TIE Advanced Вейдера. Вейдер отступает при повреждениях; уничтожать его не требуется.
6. **Красный Пять.** Управление переходит к Люку на X-wing. Полёт показан как интерактивная кат-сцена: манёвры, преследование и тепловая шахта видны в 3D. Ошибка QTE сбрасывает последовательность и расходует время.
7. **Цепная реакция.** Две торпеды загибаются в шахту; кат-сцена показывает взрыв станции и уход X-wing.

На поверхности можно дополнительно уничтожить два энергетических узла: это ослабит батареи и усилит защиту сопровождаемых кораблей. Среди противников — линейные TIE, более агрессивные асы, TIE Advanced, лёгкие зенитные и тяжёлые турболазерные батареи. Ангары, трубопроводы, вышки и дальние схватки наполняют окружение.

Вооружение X-wing — лазеры и шесть заряженных протонных торпед плюс двенадцать в запасе; Y-wing также получает ионные пушки, восемь заряженных торпед и шестнадцать в запасе. `R` перезаряжает пусковые из конечного запаса за 4,5 секунды; пауза останавливает таймер, смена оружия позволяет продолжать заряжание в фоне. Торпеды наводятся на цель в переднем секторе и наносят урон взрывом; ионные заряды временно отключают цель. Боезапас показан в HUD, при новом вылете он восстанавливается. Количество торпед — аркадный баланс. Шейдеры создают анимированную плазму двигателей и свечение лазерных/ионных выстрелов. Под приборами действует полоса-компас: контакты противников, Вейдера и союзников отслеживаются по пеленгу, а итоги вылетов (рекорд по очкам и точности) хранятся локально между сессиями.

Щиты принимают урон перед корпусом. X-wing перераспределяет энергию щитов; Y-wing использует ионное вооружение против ближайшей цели. Эти эффекты, скорость и прочность — аркадный баланс, а не справочные технические характеристики. Обычные TIE не имеют щитов. A-wing не включён в битву при Явине; он предусмотрен для будущего эпизода VI.

## Эпизод V · Битва при Хоте

В ангаре выбирается хроника: **IV · Новая надежда** (Явин) или **V · Битва при Хоте**. Хроника V — шесть фаз на замёрзшей планете:

1. **Ледяная равнина.** Пробиться к базе сквозь истребители Империи и прикрыть коридор эвакуации.
2. **Штурм базы.** Уничтожить пять AT-ST и орудийные посты у генератора щита; по пути снимается схема нагрузки щита.
3. **Шаг в ночи.** Выйти на AT-AT. Лобовая броня отражает лазеры — урон проходит по сочленениям ног и по башне, HUD подсказывает цель.
4. **Трос.** QTE-фаза: уйти к самому снегу, пройти под ногой шагохода, натянуть буксирный трос и отпустить его вверх. Ошибка отнимает шесть секунд.
5. **Падение.** Кат-сцена: машина теряет опору, валится на щит, топливо взрывается вторым взрывом.
6. **Эвакуация.** Прикрыть взлёт трёх транспортов. База потеряна, люди спасены — именно такой исход и был у Революции на Хоте.

Сцена, AT-AT, AT-ST, база и транспорты собраны процедурно из примитивов Three.js: в сборку не добавлено ни одного внешнего файла с лицензией. Правила боя, границы канона и решения по архитектуре — в [docs/EPISODE-V-HOTH.md](docs/EPISODE-V-HOTH.md), канон и разбор ассетов — в [docs/research/](docs/research).

## Графика и поведение противников

По умолчанию включён **HD**: разрешение сцены соответствует экрану, на дисплеях высокой плотности используется масштаб до 1,5×, сглаживание SMAA сохраняет мелкие детали. Игра больше не снижает разрешение автоматически. В меню паузы можно явно выбрать режим производительности и вернуться в HD. HUD остаётся чётким в обоих режимах: силуэты вооружения, реальные ячейки торпед, нагрев и прогресс перезарядки связаны с состоянием корабля.

Имперские TIE используют модель Jeroenimo с текстурированной обшивкой и картой нормалей. Исходная упрощённая модель сохранена для сравнительных проверок качества.

TIE выполняют отдельные заходы: сближаются, обозначают атаку, стреляют с упреждением, выходят из боя и заходят с фланга. Асы быстрее реагируют на видимые снаряды. На заданиях сопровождения противники выбирают союзные корабли; оставленная без прикрытия группа действительно может погибнуть. Увеличение сложности связано с манёврами и прицеливанием, а не дополнительным здоровьем.

Для вида из кабины X-wing загружается локальная модель Open Galaxy с 64 642 треугольниками и текстурами 4096 × 4096; для Y-wing остаётся процедурная кабина. В траншее есть многомасштабные скошенные панели, трубы и сигнальное освещение, отражения материалов и локальная подсветка без теней. Взрывы используют светящиеся спрайты и обломки. Шрифты и игровые ресурсы хранятся локально.

## Тактические системы

В сопровождении Золотой группы одновременно действуют TIE, тяжёлая маршрутная батарея и удалённый узел её питания. Перехват TIE немедленно защищает атакуемый корабль; уничтожение близкой батареи прекращает её огонь. Обход к дальнему энергоузлу требует времени, но отключает батарею и даёт группе передышку для перераспределения энергии: один раз восстанавливается до 25 единиц щитов каждому уцелевшему Y-wing. Состояние батареи видно в панели группы, важные объекты отмечены в пространстве, радиопереговоры реагируют на действия и повреждения. Основные маршрутные точки сохраняются; важные объекты не засчитываются вместо сопровождения. Восстановление щитов — аркадное допущение.

Лазеры требуют ручного прицеливания: голубой ромб показывает упреждение для движущейся цели, а снаряды всегда следуют направлению носа. Для наведения торпед удерживайте одну видимую цель в переднем секторе 1,7 секунды. Смена цели начинает захват заново; при потере видимости наведение отключается сразу, а прогресс постепенно убывает. Можно запустить торпеду раньше — она расходует боезапас, но летит без наведения. Пауза останавливает захват.

Поворот сильнее всего на средней скорости; разгон ограничивает угловую скорость. После поворота вектор движения догоняет нос с небольшой задержкой. Для инерционного разворота разгонитесь, удерживайте `Ctrl` и поверните: корабль некоторое время скользит по прежнему направлению. X-wing быстрее набирает скорость, тормозит и выравнивается, чем тяжёлый Y-wing. В траншее скольжение ограничено для точного прохождения створов. Форсаж меняет угол обзора и звук двигателя, добавляет небольшую вибрацию камеры без размытия изображения.

Три дополнительные тактические системы действуют во всех обычных боевых этапах. Энергия двигателей повышает тягу на 18%, но замедляет охлаждение и восстановление щитов; энергия орудий усиливает лазерный/ионный урон и охлаждение на 20%, снижая тягу; щиты восстанавливаются вдвое быстрее ценой скорости и охлаждения. `4` возвращает баланс. `V` ремонтирует 25 единиц корпуса за 3 секунды, блокирует стрельбу и прерывается попаданием (2 заряда, 20 секунд между попытками). `T` вызывает два X-wing на 10 секунд после выбора цели перед кораблём: они стреляют настоящими снарядами по противникам, не повреждая союзников (3 вызова, 25 секунд между ними).

У X-wing четыре независимых крыла вместе с двигателями и пушками плавно складываются для крейсерского режима и раскрываются для атаки. Ускорение сохраняет раскрытое боевое положение: можно одновременно разгоняться и стрелять. `X` вручную складывает или раскрывает крылья. При сложенных крыльях и во время анимации оружие заблокировано; стрельба не меняет выбранное положение. В радиопанели отображаются оригинальные нарисованные портреты говорящих персонажей.

## Устройство проекта

- `src/game/engine.js` — полёт, боевые объекты, камеры, игровой цикл.
- `src/game/world.js` — сцена, модели, станция, траншея и кабина.
- `src/game/enemy-ai.js` — заходы, перехват и реакция пилотов на видимые угрозы.
- `src/game/world-detail.js`, `src/game/render-pipeline.js` — детали окружения и постобработка.
- `src/game/data.js` — характеристики кораблей и описание эпизодов/миссий.
- `src/game/missions.js` — семь этапов, сюжетные приказы и дополнительные задачи.
- `src/game/campaign.js` — независимая логика последовательности миссий и QTE.
- `src/game/simulation.js` — расчёты урона и столкновений.
- `src/main.js`, `src/style.css` — меню, HUD и управление интерфейсом.
- `public/models/`, `public/textures/` — локальные 3D-модели и текстуры.
- `tests/` — автоматические проверки миссий и симуляции.

Чтобы добавить эпизод, зарегистрируйте его в `EPISODES`, задайте список миссий/кораблей и добавьте нужное окружение в игровой движок. Первая версия содержит одну законченную кампанию; последующие эпизоды не являются доступными уровнями.

Канон, сценарий и допущения: [docs/DESIGN.md](docs/DESIGN.md). Архитектура: [docs/TECHNICAL.md](docs/TECHNICAL.md). Авторы, источники и условия использования моделей: [docs/ASSETS.md](docs/ASSETS.md).

Дополнительные задачи включают трёхсекундное сканирование сенсора с торможением (`Ctrl`), перехват пары асов при сопровождении и уничтожение регулятора охлаждения в траншее. Янтарные сигналы предупреждают об опасных выбросах пара; уничтожение регулятора отключает их. Эти задачи дают отдельные бонусы и не заменяют основной приказ.

Звук использует локальные эффекты CC0 Kenney и rubberduck вместе с синтезом Web Audio: лазеры, торпеды, ионные пуски, щиты, взрывы, радиосигналы и меняющийся при разгоне гул двигателя. Отдельные атмосферные эффекты также синтезированы: боевая тревога перед траншейным заходом, заряд и выстрел суперлазера, уничтожение станции цепной реакцией, пролёт у стены траншеи, попадание протонной торпеды и победная фанфара. Игра получила и собственную адаптивную партитуру, написанную для неё: тема меню, остинато боя и траншеи, марш с малым барабаном, фанфара победы и нисходящая тема поражения; музыка меняется по фазам кампании, включается после первого жеста пользователя и затихает на паузе. Загрузка начинается после запуска вылета; при недоступности файлов остаётся синтез. Подробнее: [docs/AUDIO.md](docs/AUDIO.md), [источники](docs/AUDIO-SOURCES.md). Фрагменты фильма, музыка Джона Уильямса и голоса актёров не используются: и эффекты, и партитура — оригинальный синтез без цитат. Все игровые ресурсы загружаются локально; ключи и регистрация не нужны.


## Обновление 2 — Tactical Battles

- TIE действуют парами: один отвлекает, другой заходит сбоку. В рамке цели видны ранг (новичок, ветеран, лидер) и роль. Новички хуже держат курс и прицел; лидеры точнее и быстрее открывают огонь. После потери напарника TIE временно отходит либо вызывает одного аса. Уничтожьте вызывающего за 4 секунды, чтобы сорвать подкрепление; активный вызов отмечен маркером.
- **G** переключает приказ ведомым: прикрытие игрока, атака выбранной прицелом цели, защита наиболее повреждённого союзника. Вызывайте пару через **T**; действующие ведомые меняют цели без нового расхода вызова. Приказы также доступны в «Бортовых системах».
- Сохраните все три Y-wing до третьей точки сопровождения: **+150** очков, если у каждого осталось не менее 50% корпуса; **+75**, если все выжили. Потеря корабля лишает этого бонуса, но оставшуюся группу можно довести до цели. Реальные батарея, энергоузел и перехватчики сохраняют свои независимые последствия.
- Прошедший через щиты урон повреждает двигатели, оружие и сенсоры. Падает тяга/разгон, замедляются стрельба/охлаждение и захват торпеды. Корабль остаётся управляемым; эти эффекты не добавляют размытие изображения.
- **B** выбирает приоритет ремонта: корпус → двигатели → оружие → сенсоры. **V** чинит выбранное за 3 секунды: +25 корпуса либо до +40% целостности системы. Два заряда и 20-секундный откат общие; попадание прерывает ремонт. Выбор блокируется на время работ. Пауза останавливает все таймеры.


## Точное наведение и первый торпедный заход

Турели и TIE рассчитывают перехват по наблюдаемой скорости цели с учётом реальной точки вылета и времени жизни снаряда. Разброс ограничен профилем оружия: прямой равномерный полёт под огнём теперь опасен. Меняйте курс после предупреждения или выпущенного залпа: вражеские лазеры не самонаводятся. Урон и здоровье противников сохранены; лёгкие/тяжёлые батареи выпускают более быстрые аркадные снаряды (420/520 игровых м/с).

Между Золотой группой и прикрытием Клина добавлен **«Заход Красного Лидера»**. Сбейте три TIE, защитите X-wing Гарвена Дрейса и достигните отмеченного вектора. Оба условия обязательны, очередная волна или ожидание не заменяют маршрут. Затем показаны торпедный пуск, попадание рядом с шахтой и потеря Красного Лидера. Источник сюжетного результата: [официальная биография Гарвена Дрейса](https://www.starwars.com/databank/garven-dreis). Прикрытие и порядок игровых задач остаются аркадной адаптацией боя.

Разработчикам: параметры юнитов и выбор цели — `enemy-units.js`; оружие, перехват и управление башней — `enemy-fire-control.js`; манёвры — `enemy-ai.js`; координация — `enemy-squadron.js`. Эти модули не зависят от номера эпизода или Three.js.
