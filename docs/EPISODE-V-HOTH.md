## 1. Границы канона и адаптации

Канон обязателен в: последовательности событий, роли AT-AT, механике буксирного троса, финале (потеря базы при спасённых людях), оформлении (Хот — холодная, заснеженная планета; Империя — AT-AT/AT-ST/пехота; Повстанцы — X-wing/Y-wing/транспорты).

Явно адаптации (обязано быть отражено в UI и в `docs/DESIGN.md`):

1. **Трос навешивает X-wing, а не T-47.** В каноне («Империя наносит ответный удар») ногу AT-AT обвивают тросом **снегохода T-47** — это делают Ведж Антиллес и Уэс Джаксон; Люк уничтожает вторую машину мечом и термодетонатором. Здесь игрок остаётся на своём X-wing: сцена троса перенесена на корабль игрока, чтобы сохранить единое управление отрядом. Это осознанное расхождение с каноном, а не ошибка.
2. **Игрок — не Люк.** Вне QTE-фазы игрок — безымянный пилот Повстанческого Альянса. В QTE-фазе «Трос» игрок **берёт роль Люка**: камера и хореография следуют канонической сцене, но каждое действие остаётся за игроком. Путаницы быть не должно: это указано в брифинге фазы и в радио.
3. **AT-AT не убивается очередью в упор.** Фронтальный броневой лист отражает лазеры — урон проходит только по открытым целям (ноги, башня). Это игровое правило, вдохновлённое каноном, а не цитата.
4. **Один AT-AT в эпизоде.** Канон показывает машины Империи числом, но игровая сцена строится вокруг одной машины — той, которую нужно уронить тросом.
5. **Победа = эвакуация, а не разгром Империи.** Революция теряет Хот; спасённые корабли уходят. В фильме скандала в Совете Революции нет — Империя просто выигрывает этот бой, и Революция отступает. Финал эпизода повторяет именно это.
6. **AT-ST — машина с живым экипажем**, а не дроид-пехота. В игре это шагающий «снегоступ» под управлением экипажа; дроидов-пехоты в эпизоде нет.
7. **Энергощит падает.** В каноне щит базы держат генераторы, и штурм их пробивает. В эпизоде щит не «удерживается» — он рушится, и это видно по сцене.
8. **Числа и тайминги** — аркадный баланс, а не реконструкция фильма. Высота AT-AT в игровых единицах (группа масштабирована ×1.9) не равна каноническим 22,5 м: масштаб игры задаёт собственную систему, и «шагоход» читается за счёт четырёх ног, размеров базы и реакции камеры.

Запрещено: заимствовать фрагменты фильма, музыку, кадры; использовать имена/логотипы Disney/Lucasfilm; выдавать адаптации за канон.

## 2. Структура эпизода

Эпизод добавляется как `EPISODES.episode5` в `src/game/data.js` со своим массивом `missions`.
Идентификатор эпизода: `episode5`. Название: «Битва при Хоте».

**Типы фаз уникальны внутри эпизода** (директор миссий `mission-events.js` ищет миссию по `type`), поэтому для Хота вводятся собственные типы: `hoth-arrival`, `hoth-assault`, `hoth-atat`, `hoth-tow`, `hoth-fall`, `hoth-evacuation`. Эпизод IV сохраняет свои типы (`combat`, `surface`, `escort`, `assault`, `defend`, `trench`, `qte`, `cinematic`) без изменений.

Правило прогресса в кампании должно стать **data-driven** (`mission.progress = { rule, kind, target }`), с legacy-картой для Эпизода IV, иначе Эпизод V потребует хардкода в `campaign.js`. Поддерживаемые правила: `kills` (по `kind`), `checkpoints`, `escort`, `assault`, `at-at` (уничтожение/ослабление AT-AT).

| # | Тип миссии | Название | Цель | Каноническая привязка |
| --- | --- | --- | --- | --- |
| 1 | `hoth-arrival` | Ледяная равнина | Пробиться к базе сквозь истребители Империи, прикрыть коридор эвакуации | Блокада Хота, первый рубеж обороны Революции |
| 2 | `hoth-assault` | Штурм базы | Уничтожить AT-ST и орудийные позиции у щита | Наземная атака Империи, разрушение энергощита |
| 3 | `hoth-atat` | Шаг в ночи | Повредить башню и ноги AT-AT, выжить под его огнём | Броня AT-AT, прицеливание в открытые участки |
| 4 | `hoth-tow` (QTE) | Трос | Обвить тросом ногу AT-AT и уйти вверх | Сцена Люка с буксирным тросом |
| 5 | `hoth-fall` (cinematic) | Падение | — | Падение AT-AT, взрыв, броня в снегу |
| 6 | `hoth-evacuation` | Эвакуация | Прикрыть взлёт транспортов, покинуть зону | Транспорты Революции уходят с Хота; база потеряна |
| 7 | `victory` | Новая надежда | — | Революция теряет базу, но сохраняет людей и флот |

Переходы: фаза 3 завершается, когда AT-AT обескровлен/ослаблен (порог HP); фаза 4 запускается автоматически; фаза 5 — автоматический cinematic; фаза 6 идёт, пока транспорты не взлетели; затем `victory`.

## 3. AT-AT — правила боя

**Внешность.** Четыре ноги, корпус с наклонной передней бронёй, башня с орудием, «шатающаяся» походка. **Все модели процедурные** (решение §6): никаких загрузок, никаких лицензий, ~700–1500 треугольников, отдельные узлы `hip → thigh → knee → shin → foot` для адресации частей.

**Поведение.**

| Параметр | Значение | Комментарий |
| --- | --- | --- |
| Скорость шага | 18 м/с (аркадно 24) | медленно, но неприцельно |
| HP | 900 | 8–10 залпов лазеров в открытую цель |
| Броня | фронтальный лист: урон ×0.05 | выстрелы в лоб отскакивают (визуально — искры) |
| Открытые цели | ноги (×1.6), башня (×2.2), спина (×1.2) | ноги — обязательная цель для QTE |
| Орудие | телеграф 1.2 с → снаряд 220 м/с → разрыв 2.4 с | видно, можно уклоняться |
| Шаговый цикл | 4 ноги, шаг 1.1 с, синхронно-диагональный | процедурная IK, без внешней анимации |
| Урон игроку | 22 от прямого попадания, 6 от осколков | |

**Уязвимость по канону (обязательное правило):** лобовая броня не пробивается лазером. Урон наносится по ногам, башне и корме. Это же правило объясняет, почему тросом обвивают ногу.

**Обрушение (после QTE).** Трос зафиксирован на одной ноге → машина теряет опору: вращение вокруг зафиксированной ноги (2.2 с), падение корпуса (1.4 с), удар → взрыв, разлёт обломков, вторичный взрыв топлива (3.5 с), затем тлеющий силуэт в снегу. Камера: облёт (следящая камера за падающей машиной), затем общий план базы.

## 4. QTE «Трос» (фаза 4)

Используется существующий QTE-пайплайн (`campaign.qteInput`, стадии с `key`, `label`, `duration`). Набор допустимых клавиш должен расширяться полем миссии `qteKeys` (по умолчанию — текущие `QTE_KEYS`: `KeyA`, `KeyD`, `KeyW`, `Space`).

| Стадия | Клавиша | Длительность | Что происходит на экране | Канон |
| --- | --- | --- | --- | --- |
| 1 | `KeyA` | 2.0 с | Снижение к самому снегу, камера переходит в погонный вид | Люк уходит вниз к снегу |
| 2 | `KeyD` | 2.0 с | Пролёт под ногой AT-AT, трос ложится на ногу | обвивка ноги |
| 3 | `KeyW` | 2.5 с | Натяжение троса, машина клонится | машина теряет равновесие |
| 4 | `Space` | 2.0 с | Отпустить трос и уйти вверх; AT-AT валится | финал сцены |

Провал (неверная клавиша или истечение окна) → повтор стадии с потерей 6 с общего времени (`retryPenalty`), без рестарта фазы. Полный провал времени → провал миссии с сообщением «AT-AT дошёл до базы.»

Во время QTE стрельба заблокирована (как в существующей фазе `qte`).

## 5. Эвакуация (фаза 6)

- Транспорты (3–4 корабля) стоят на площадке базы, затем взлетают по очереди (интервал 2.5 с), набирают высоту и уходят в сторону флота.
- Игрок сопровождает колонну: сбивает отставших истребителей Империи, отмечает транспорты в HUD (метки + дистанция).
- Камера периодически показывает базу (снежная равнина, горящие остатки щита, силуэты AT-ST) — «мы потеряли базу».
- Финал: транспорты уходят за горизонт, камера остаётся на базе, HUD показывает «РЕВОЛЮЦИЯ СПАСЕНА · ХОТ ПОТЕРЯН».

## 6. Окружение и сцена: полностью процедурно

**Решение:** скачивание моделей отклонено. Найденные AT-AT в Sketchfab — CC BY (нужен логин и атрибуция) либо CC BY-NC (коммерческое использование запрещено); ни одной CC0-модели нет. Подробный разбор — `docs/research/EPISODE-V-ASSETS.md`; найденные кандидаты фиксируются там как вариант «на будущее», но в сборку не попадают.

Новая сцена Хота (`src/game/hoth-scene.js`, отдельный файл, координатор подключает):

- Снежная равнина: большая плоскость со снежным материалом (холодный оттенок, лёгкий блеск) + лёгкий «горизонтный» градиент.
- Ледяные скалы и айсберги: инстансы (один геометрический прототип, 10–16 инстансов, разброс по сиду).
- База Повстанцев: ангары, стены, посадочная площадка с транспортами, генератор щита, башни орудий — всё из примитивов в стиле sci-fi (тёмный металл + холодные акценты + тёплые очаги).
- Транспорты: 3–4 корабля из примитивов (корпус, крылья, двигатели) с эмиссией.
- AT-AT: процедурная модель из примитивов (корпус, броня, башня с орудием, 4 ноги с отдельными узлами).
- Ночное небо Хота, слабый свет звезды; снегопад — одна `Points`-система.

Требования к производительности: сцена не должна добавлять более ~120 draw calls; AT-AT — один инстанс с 4 анимируемыми ногами; снег — одна `Points`-система.

### Принятые решения по ходу интеграции

1. **Правило прогресса — data-driven.** `campaign.js` больше не ветвится по `mission.type`: миссия объявляет `progress: { rule, kind, target }`, а `LEGACY_RULES` сохраняет поведение Эпизода IV байт-в-байт. Правила: `kills`, `escort`, `checkpoints`, `assault`, `qte`, `cinematic`.
2. **QTE определяется данными, а не типом.** Кампания отдаёт QTE-стадии для любой миссии с полем `qte`; набор клавиш расширяется полем `qteKeys`.
3. **Правило выбора эпизода.** `game.setEpisode(id)` пересоздаёт кампанию и директора миссий с миссиями эпизода; ангар предлагает все хроники.
4. **AT-AT масштабируется ×1.9** (`AT_AT_SCALE`), радиусы попаданий заданы константой `AT_AT_RADIUS` (сочленения ног 6, башня 10.5, корпус 26). Проверка попадания — свип отрезка снаряда, поэтому быстрый болт не проскакивает мимо сочленения.
5. **Лобовая броня отражает выстрел полностью** (урон 0), а не «5 % урона»: HUD прямо пишет, что броня отвела удар. Урон проходит по сочленениям ног и по башне.
6. **Хит-тест сочленений идёт по всему отрезку снаряда**, а не по одной точке: снаряд мог пройти рядом с ногой между кадрами.

### Контракты (обязательны; иначе модули не стыкуются)

```js
// src/game/at-at.js — чистая модель, без Three.js и DOM
export function createAtAtUnit({ variant = 'assault', seed = 1, stats = {} } = {}) -> {
  update(dt, { playerPosition, basePosition, targetId }) -> { move, aim, fire, phase },

  dispose(),
}
export function createAtAtMesh() -> THREE.Group  // с узлами legs[4].hip/.knee/.foot, head, body
```

## 8. Критерии приёмки (Definition of Done)

1. Эпизод выбирается в ангаре; Эпизод IV не сломан (все существующие тесты зелёные).
2. Все 7 фаз проходятся: спавн, цель, переход, HUD, радио.
3. AT-AT: шагает (процедурная IK-походка), стреляет телеграфированным снарядом, броня блокирует лобовые выстрелы, ноги/башня получают урон, трос цепляется, машина падает со спецэффектами.
4. QTE «Трос»: 4 стадии, повтор при ошибке, провал при исчерпании времени, корректная камера.
5. Эвакуация: транспорты взлетают, сопровождение работает, финальный экран честно говорит о потере Хота.
6. Нет ошибок в консоли, нет падения FPS ниже 30 в HD на средней машине.
7. Тесты: `npm test` — зелёные (включая новые), `npm run build` — успешно.
8. `docs/ASSETS.md` фиксирует, что ассеты Эпизода V процедурные, и перечисляет отклонённые внешние модели.
9. README и `docs/DESIGN.md` дополнены описанием Эпизода V.
